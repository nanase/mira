# 使い方

## 初めて起動したとき

Claude Code の設定フォルダ（`%USERPROFILE%\.claude` など）が見つかると、確認ダイアログが 2 回出ます。

1. 登録の確認: フォルダをプロファイルとして登録するかを選びます
   - 登録しても、フォルダの中身は変わりません
2. トークンの自動更新の確認: 期限切れのときに、Mira がトークンを更新して書き戻してよいかを選びます
   - 許可しなければ、読み取りのみで動きます
   - 詳しくは [安全のための設計](security.md) を参照してください

登録したプロファイルごとに、トレイアイコンが 1 つ出ます。

## プロファイルを増やす

`CLAUDE_CONFIG_DIR` で設定フォルダを分けていれば、フォルダごとにプロファイルを作れます。

- 設定の「プロファイル」で「フォルダを追加」を押し、フォルダを選びます
- ホーム直下の `.claude` で始まるフォルダは、「もう一度検出」で見つけられます

## ポップアップの見方

トレイアイコンをクリックすると開きます。

| 項目 | 内容 |
|---|---|
| セッション | 5 時間ごとの制限 |
| すべてのモデル | 週間の制限 |
| 追加使用量 | 追加使用量を有効にしているときだけ出ます |
| クレジット残高 | 残高があるときだけ出ます |

制限の窓がまだ始まっていなければ、リセット時刻の代わりに「開始を待っています」と出ます。

バーの上の縦線（時間マーカー）は、制限の窓のうちどこまで時間が経ったかを示します。

- バーがマーカーより左にあれば、このペースでは上限に届きません
- バーがマーカーより右にあれば、上限に届くペースで使っています

時間マーカーの色は、設定の「表示」でペース色（6 段階）に変えられます。色は、今のペースで使い続けたときの期末の使用率で決まります。

| 色 | 期末の予測使用率 |
|---|---|
| 緑 | 50% 未満 |
| ティール | 50〜75% |
| 黄 | 75〜90% |
| 橙 | 90〜100% |
| 赤 | 100〜120% |
| 紫 | 120% 以上 |

ヘッダーのボタン:

- ピン: ポップアップをウィンドウとして固定します。固定中は、ボタン以外の場所をつかんで動かせます
  - 固定したまま終了すると、次の起動で同じ場所に固定して出ます
  - 最前面に出すかどうかは、設定の「一般」で選べます。最前面に出さないときは、トレイアイコンをクリックすると前に出ます
- 矢印: 今すぐ取得し直します
- 歯車: 設定を開きます

## トレイアイコン

設定の「表示」で、スタイルを 4 種類から選べます。

| スタイル | 表すもの |
|---|---|
| リング | 5 時間の使用率 |
| 二重リング | 外側が 5 時間、内側が週間 |
| 数字 | 5 時間の使用率 |
| 縦バー 2 本 | 左が 5 時間、右が週間 |

- 「時間マーカーを表示」を有効にすると、アイコンにも時間マーカーが入ります（数字のスタイルを除く）
- プロファイルが 2 つ以上あると、リングの中央にプロファイル名の頭文字が入ります
- マウスを乗せると、プロファイル名とリセット時刻が出ます

## 表示位置を戻す

ポップアップが画面の外に出てしまったときは、トレイアイコンの右クリックメニューから「表示位置の復元」を選びます。ポップアップがトレイアイコンの隣に戻ります。固定は解けません。設定画面が開いていれば、トレイアイコンのあるディスプレイの中央へ移ります。

## 終了する

トレイアイコンの右クリックメニューか、設定画面の左下の「Mira を終了」から終了します。設定画面を閉じても、Mira はトレイに残ります。
