# 使い方

## 初めて起動したとき

Claude Code の設定フォルダ（`%USERPROFILE%\.claude` など）が見つかると、確認ダイアログが 2 回出る。

1. 登録の確認: フォルダをプロファイルとして登録するか選ぶ
   - 登録してもフォルダの中身は変わらない
2. トークンの自動更新の確認: 期限切れのとき、Mira がトークンを更新して書き戻してよいか選ぶ
   - 許可しなければ読み取りのみで動く
   - 詳しくは [安全のための設計](security.md) を参照

登録したプロファイルごとに、トレイアイコンが 1 つ出る。

## プロファイルを増やす

`CLAUDE_CONFIG_DIR` で設定フォルダを分けていれば、フォルダごとにプロファイルを作れる。

- 設定の「プロファイル」で「フォルダを追加」を押し、フォルダを選ぶ
- ホーム直下の `.claude` で始まるフォルダは、「もう一度検出」で見つけられる

## ポップアップの見方

トレイアイコンをクリックすると開く。

| 項目 | 内容 |
|---|---|
| セッション | 5 時間ごとの制限 |
| すべてのモデル | 週間の制限 |
| 追加使用量 | 追加使用量を有効にしているときだけ出る |
| クレジット残高 | 残高があるときだけ出る |

バーの上の縦線（時間マーカー）は、制限の窓のうちどこまで時間が経ったかを示す。

- バーがマーカーより左にあれば、このペースでは上限に届かない
- バーがマーカーより右にあれば、上限に届くペースで使っている

時間マーカーの色は、設定の「表示」でペース色（6 段階）に変えられる。色は、今のペースで使い続けたときの期末の使用率で決まる。

| 色 | 期末の予測使用率 |
|---|---|
| 緑 | 50% 未満 |
| ティール | 50〜75% |
| 黄 | 75〜90% |
| 橙 | 90〜100% |
| 赤 | 100〜120% |
| 紫 | 120% 以上 |

ヘッダーのボタン:

- ピン: ポップアップをウィンドウとして固定する。固定中はヘッダーをつかんで動かせる
- 矢印: 今すぐ取得し直す
- 歯車: 設定を開く

## トレイアイコン

設定の「表示」で、スタイルを 4 種類から選べる。

| スタイル | 表すもの |
|---|---|
| リング | 5 時間の使用率 |
| 二重リング | 外側が 5 時間、内側が週間 |
| 数字 | 5 時間の使用率 |
| 縦バー 2 本 | 左が 5 時間、右が週間 |

- 「時間マーカーを表示」を有効にすると、アイコンにも時間マーカーが入る（数字のスタイルを除く）
- プロファイルが 2 つ以上あると、リングの中央にプロファイル名の頭文字が入る
- マウスを乗せると、プロファイル名とリセット時刻が出る

## 終了する

トレイアイコンの右クリックメニューか、設定画面の左下の「Mira を終了」から終了する。設定画面を閉じても、Mira はトレイに残る。
