# 安全のための設計

Mira は、利用者の承諾なしに既存のファイルを変更しません。この文書では、Mira が何を読み、何を書き、どこと通信するかをまとめます。

## 読むもの

| ファイル | 用途 |
|---|---|
| `<設定フォルダ>\.credentials.json` | 使用量の取得に使うアクセストークン |

- 設定フォルダは Claude Code のもの（`%USERPROFILE%\.claude` など）です
- 見つけたフォルダは、登録する前に確認ダイアログで尋ねます

## 書き込むもの

### Claude Code の認証情報

書き込むのは、トークンの自動更新を許可したプロファイルだけです。許可はプロファイルごとに確認ダイアログで尋ね、設定の「プロファイル」でいつでも取り消せます。

| 項目 | 内容 |
|---|---|
| 対象 | `<設定フォルダ>\.credentials.json` |
| 書き換える項目 | `claudeAiOauth` の `accessToken`、`refreshToken`、`expiresAt` の 3 つ |
| タイミング | アクセストークンの期限切れを検出したときだけ |

書き戻す理由: Mira がトークンを更新すると、古い refresh token は使えなくなります。書き戻さないと、同じファイルを使う Claude Code のログインが切れてしまいます。

Claude Code 自身の更新と重ならないよう、次のように扱います。

- 期限の 60 秒前から期限切れとみなします
- 更新する直前にファイルを読み直し、すでに新しいトークンに替わっていれば更新しません
- 書き込む直前にもう一度読み直し、3 項目だけを差し替えます
- 一時ファイルに書いてから置き換え、書きかけのファイルを残しません

許可しなければ、読み取りのみで動きます。期限が切れたら、Claude Code を起動するようポップアップで案内します。

### Mira 自身のデータ

| 内容 | 場所 |
|---|---|
| 設定とプロファイル | `%APPDATA%\dev.mira.tray\config.json` |
| 使用率の履歴（90 日分） | `%LOCALAPPDATA%\dev.mira.tray\history\` |

- トークンは Mira のデータに複製しません
- プロファイルを外すと、そのプロファイルの履歴も消します
- 設定の「履歴」で、記録を止めたり、プロファイルごとに履歴を消したりできます
- 「Windows へのサインイン時に起動」を有効にすると、スタートアップ（レジストリの `Run` キー）に Mira を登録します

## 通信先

| 通信先 | 用途 |
|---|---|
| `api.anthropic.com` | 使用量の取得 |
| `platform.claude.com` | トークンの更新（許可したプロファイルだけ） |
| `status.claude.com` | 稼働状況の取得 |

- 使用量を消費するリクエスト（メッセージの送信など）は送りません
- 利用状況の解析データは送りません
- 使用量の取得は、設定した間隔（既定 5 分）ごとに行います。拒否（HTTP 429）されたら、間隔を空けます

## 画面

- 画面は、外部のスクリプトやフォントを読み込みません
- 画面から開けるリンクは、稼働状況のページ、Mira のリポジトリ、参考にしたプロジェクトの 3 つに限ります
